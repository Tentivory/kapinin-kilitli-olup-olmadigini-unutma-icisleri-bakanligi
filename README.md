# kapinin-kilitli-olup-olmadigini-unutma-icisleri-bakanligi
Kapının kilitli olup olmadığını unutmayı resmi iç güvenlik krizi, milli kilit egemenliği ihlali ve eşik protokolü sapması sayan; anahtarı jandarma, eşiği sınır, 'biraz dönerim bakarım' cümlesini olağanüstü hâl ilan eden Bakanlık. Gerçekten çalışır. Kapılar artık vilayettir.
